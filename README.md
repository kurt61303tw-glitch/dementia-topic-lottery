## 🎯 核心特色（自由選擇，免綁定資料夾）

1. **隨機抽籤 ＋ 自由指定題目（雙模式）**：
   - 點擊 **「🎲 開始抽題」**：隨機為當前組別抽出情境題目（可開關滾輪動畫）。
   - 點擊下方卡片 **「🎯 自由選此題」**：講師或小組可從 24 題中自由指定要討論的題目。
2. **只要檔案名稱，無資料夾路徑限制**：
   - 每題清清楚楚顯示標準檔案名稱（例如：`溝通題目1：重複提問＋時間錯亂＋焦慮升高.mp4`）。
   - 提供「複製檔名」按鈕。
   - 若要播放影片，可隨時點擊 **「📂 自由選取本機影片播放」** 從任何位置載入，或**直接把影片拖曳進視窗**立即播放。
   - 若不載入影片，也能直接瀏覽完整案例心理背景、反思題目與講師回饋。
3. **組別管理（2~12 組）**：
   - 自由設定組數、切換當前組別，自動記錄每組已討論的題目。
4. **內建研討計時器**：
   - 預設 3 分鐘小組研討倒數，支援暫停、+1分鐘與重設。
